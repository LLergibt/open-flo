## Доступность и ограничения

Контент прокручивается по вертикали; строки компоновки, которым может не хватить ширины, преимущественно используют FlowRow. Текст использует sp, без принудительного ограничения числа строк. Панель сообщения задаёт минимальную высоту и может увеличиваться. Кнопка имеет минимальную высоту 48 dp. Заголовок помечен как heading, обновляемые сообщения и статус — live region; декоративные элементы окна и символ статуса исключены из отдельного чтения.

На ширине 411 dp код выбирает мобильную композицию. Увеличенный системный шрифт не отключается, фиксированной высоты для текстовых блоков нет. Статическая проверка не устанавливает отсутствие обрезания во всех системных масштабах: нужны скриншоты и навигация на устройстве, в том числе с увеличенным шрифтом.

Сборка, lint, установка, фактическое получение сообщения и визуальная проверка на устройстве выполняются координатором и агентом Android отдельно. В рамках этого ревью они не запускались. Допустимое различие нижней метки платформы сохранено: `web / dev` и `android / dev`. Конкретные детали HTTP-ошибки Android не выдумывает: слой состояния передаёт только общий признак ошибки.

Изменён только этот отчёт. Производственный код в рамках ревью не редактировался.


## Проверка координатором на Nothing

17 ноября 2026 года: обновлённый нативный интерфейс установлен поверх прежнего APK с тем же отладочным ключом. Проверены получение реального текста SQLite и состояние «Подключено».

Показаны «Соединение не установлено», «Повторить подключение» и «Нет соединения». После восстановления проброса и нажатия кнопки снова получены «Привет из SQLite» и «Подключено».
