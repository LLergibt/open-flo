# Общий интерфейс Android и веба

Пользователь выбрал веб-интерфейс каркаса как визуальный эталон. Источники текущего экрана: `apps/web/src/App.svelte` и `apps/web/src/style.css`. Android воспроизводит его нативными компонентами Compose.

## Структура экрана

Сверху размещаются `flo / local` и бейдж `КАРКАС · 001`. Затем окно с заголовком `connection.exe`, декоративными символами управления, рамкой толщиной 2 и жёсткой тенью со смещением 5. Символы окна не являются действующими кнопками.

Внутри: надпись `СВОЙ СЕРВЕР · СВОИ ДАННЫЕ`, заголовок `Проверка подключения`, пояснение, цепочка `SQLite → API → Приложение`, панель сообщения, кнопка и статус. Окно завершается нижней строкой с именем проекта и обозначением платформы. Под окном — подпись о демонстрационных данных.

На узком экране кнопка занимает всю доступную ширину, статус находится под ней. Контент прокручивается при нехватке высоты и увеличенном системном шрифте. На широком экране композиция ограничена шириной 760 и центрирована. Safe areas учитываются отдельно от внутренних отступов.

Моноширинная гарнитура используется для бренда, заголовков, коротких меток, сообщения и кнопки. Основное пояснение и детали используют читаемую системную гарнитуру без засечек. Масштаб шрифтов следует веб-иерархии; не использовать прежний увеличенный Android-заголовок как отдельный стиль.

## Состояния

| Состояние | Сообщение | Кнопка | Статус |
|---|---|---|---|
| Загрузка | Получаем сообщение… | Загрузка…; недоступна | Ожидание |
| Успех | Реальное сообщение API и источник sqlite | Получить снова | Подключено |
| Ошибка | Соединение не установлено; пояснение | Повторить подключение | Нет соединения |

Статус различается текстом и знаком. Не подставлять тестовый успешный текст при ошибке. Не выдумывать подробности HTTP, если слой данных их не передаёт. Нижняя метка платформы может различаться: `web / dev` и `android / dev`.

## Предпочтения

Сохранять минималистичный Y2K/ретро: ограниченную персиковую палитру, тонкие рамки, оконные детали и свободное пространство. Генерация изображений и сгенерированные иллюстрации запрещены. Текущий экран не использует изображения, внешние шрифты или CDN. Будущие семантические цвета календаря остаются согласованными отдельно: красный для месячных, синий для предполагаемого фертильного окна, дополнительные подписи и формы для различения фактов и прогнозов.


## Экраны авторизации и админки

Те же цвета, моноширинные акценты, оконные панели и прямоугольные кнопки используются для входа, аккаунта, управления пользователями и парами. Веб остаётся визуальным эталоном Android. Пароли вводятся в скрытые поля, не сохраняются и не выводятся в статусах, логах или подтверждениях. Обычный пользователь видит только свою пару; административные действия отделены и подписаны. Подтверждение разрыва пары объясняет прекращение партнёрского доступа. Существующая тестовая страница больше не является главным экраном продукта.
